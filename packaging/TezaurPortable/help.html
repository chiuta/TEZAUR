Tezaur Portable

Asistent local pentru redactarea tezei. Indexează cărțile și articolele tale și redactează doar pe baza pasajelor găsite, cu citări [n] către fișier și pagină. Nimic nu părăsește calculatorul.

Pornire rapidă

  1. Copiază cărțile/articolele (pdf, docx, epub, txt, md, html, tex) în Data\Library. Dacă folosești Zotero, pune acolo și exportul .bib (BibTeX): citările devin „Autor (An), p. N”.
  2. Pornește TezaurPortable.exe și scrie /ingest.
  3. Caută fără model: /search recunoașterea calificărilor
  4. Pentru răspunsuri și capitole ai nevoie de un model local. Două variante:
    • Ollama: dacă l-ai pus în App\Ollama, pornește singur; altfel rulează ollama serve. O dată: ollama pull llama3.1:8b (opțional ollama pull bge-m3 pentru căutare după sens).
    • Jan (mai simplu, cu interfață): descarcă un model în Jan, apoi Settings → Local API Server → Start Server. În Data\settings\tezaur.conf pune api = jan și model = <id> (comanda /models arată id-urile).

Comenzi

întrebare liberă             → răspuns cu citări
/search text                 → pasajele cele mai relevante
/compare întrebare           → ce spun sursele, unde sunt de acord / nu
/gaps tema                   → ce e bine susținut, ce e slab, ce lipsește
/summarize carte             → rezumatul unei cărți întregi (lent)
/only text                   → limitează la documentele care conțin „text” (/only singur: anulează)
/ask întrebare --decompose   → caută mai larg, din mai multe unghiuri
/flashcards tema -o carduri.tsv → carduri de studiu cu sursă (importabile în Anki)
/draft "Tema" --kind lit-review → recenzie de literatură (și: introduction, critical-review)
/doctor [--generate]         → verifică serverul, modelul, indexul și .bib; spune ce e de reparat
/draft "Secțiune" --notes "idee 1
idee 2" -o sectiune.md        → ciornă (salvată în Data\Output)
/outline "Tema"              → schiță de capitol
/ingest [cale ...] [--force] → indexează (fără cale: Data\Library); --force reciteşte tot
/sources   /models   /help   /quit

Setări

Data\settings\tezaur.conf: api (ollama / jan / openai), host, api_key, model, embed_model, num_ctx (doar Ollama).

Portabilitate

Dacă folosești Jan, acesta își păstrează propriul folder de date (mutabil din setările Jan); portabil este doar TEZAUR.

Tot ce este al tău stă în Data\ (index, bibliotecă, setări, ciorne, modelele Ollama din pachet). Folderul poate fi mutat pe alt stick sau alt calculator; căile din index sunt relative. Nu se scrie nimic în registry, %APPDATA% sau profilul utilizatorului.

Limite

Verificarea citărilor este mecanică: arată dacă pasajul citat există, nu dacă susține afirmația. Deschide pagina. PDF-urile scanate au nevoie de OCR. DOCX/EPUB nu au numere de pagină. Cardurile Anki nu au fost testate în Anki. Rezumatele lungi păstrează referințele de pagină prin mai mulți pași: verifică-le prin sondaj. Modelele mici parafrazează aproximativ.
